# 🌱 AgroTech - Agrinho 2026

Projeto desenvolvido para o programa **Agrinho 2026** (SENAR-PR), com foco no tema "Agricultura e Tecnologia". O site explora como a Agricultura 4.0, o uso de dados, a automação e a conectividade estão revolucionando o campo e promovendo a sustentabilidade.

---

## 🎯 Sobre o Projeto

A união entre a agricultura tradicional e as novas tecnologias é essencial para o futuro. Este site tem um caráter educativo e informativo, apresentando de forma acessível os principais avanços tecnológicos no setor agropecuário e desmistificando a relação entre tecnologia e meio ambiente.

**Principais tópicos abordados:**
* Drones Agrícolas
* Sensores e Internet das Coisas (IoT)
* Inteligência Artificial e Big Data
* Maquinário Autônomo
* Sustentabilidade e Agricultura de Precisão

---

## 🚀 Funcionalidades

O site foi pensado para oferecer uma ótima experiência ao usuário, contando com:
* **Design Responsivo:** O layout se adapta perfeitamente a computadores, tablets e smartphones.
* **Navegação Dinâmica:** Rolagem suave (smooth scroll) ao clicar nos itens do menu.
* **Interatividade:** Efeitos de hover nos blocos de conteúdo para destacar as informações.
* **Acessibilidade de Navegação:** Botão inteligente de "Voltar ao Topo" que aparece apenas quando necessário.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias fundamentais do desenvolvimento web:

* **HTML5:** Estruturação semântica do conteúdo para facilitar a leitura por motores de busca e garantir acessibilidade.
* **CSS3:** Estilização visual utilizando Flexbox e CSS Grid para organização do layout, além de variáveis de cores para manter a identidade visual padronizada.
* **JavaScript (Vanilla JS):** Lógica de programação para adicionar interatividade ao site (Menu com rolagem suave e botão de voltar ao topo) sem a necessidade de bibliotecas externas.

---

## 💻 Como executar o projeto

Para ver o site funcionando na sua máquina, siga os passos abaixo:

1. Faça o download deste repositório ou clone usando o comando:
`git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git`
2. Abra a pasta do projeto no seu computador.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador padrão.
4. (Opcional) Você também pode abrir a pasta no VSCode e utilizar a extensão *Live Server* para visualizar as alterações em tempo real.
